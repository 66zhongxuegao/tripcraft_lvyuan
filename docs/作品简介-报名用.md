## 主版本（约 1300 字，报名表「作品简介」栏可直接粘贴）

**（1）解决什么问题**

入境游需求在增长，能独立接单的定制师不够用：2025 年全国出入境 6.97 亿人次创历史新高，其中免签入境外国人 3008 万人次、同比增长 49.5%，相当比例的游客会通过 Trip.com 对接平台认证的旅行定制师。

培养方式却仍停留在师傅带教、拿真实客户练。据上海途悠国际旅行社（有入境游定制业务的旅行社）一线调研：平台认证目前是线上课程加一次电话面试，新人入职后前 3 个月通常只能承接简单订单，人力成本照付；派单有硬性时限——1 小时内必须致电客户、4 小时内必须上传方案，新人不敢独立接单；师傅每天约 1 小时消耗在重复答疑上。入境游定制还比一般定制游多出四层叠加难度：跨语种沟通、宗教饮食与礼仪隐私边界、免签与过境政策的时效性、跨境支付与多语种地接履约。任一环节出错，代价都由真实客户承担。行业缺的不是教材，而是可以安全试错、并且能量化验收的训练环境。

**（2）面向哪类用户**

面向入驻携程的定制游商户，也就是旅行定制师所在的旅行社。直接使用者是新人定制师与带教师傅；管理方与付费方是旅行社负责人，以及平台的商户运营与培训团队。实训界面按携程定制游工作台（vbooking）还原，训练在真实平台的界面与流程里完成，训练口径与平台考核口径一致。

**（3）核心能力**

系统把定制师从接单到复盘的真实工作流拆解为 13 个可考核步骤（任务初始化 → 抢单接单 → 需求挖掘 → 需求结构化确认 → 资源询价 → 行程方案 → 分项报价 → 客户反馈迭代 → 成交录单 → 资源锁定与行前 → 行中应急 → 行后结算 → 复盘评分）。学员在倒计时、预算、资源与突发事件四重压力下连续交付真实工作物：需求确认单、逐日行程方案、分项报价单、合同与保险、出团通知书、地接结算核对单。

技术亮点：13 步状态机，每一步都明确输入物、完成条件与失败回退；8 维 61 个技能点的原子评分，每一分都必须引用学员原话或交付物片段作为证据坐标，可回放、可反查；双层拦截网，确定性校验（分项加总、毛利率、保险项、日期自洽）叠加语义合规红线（宗教饮食、证件入境、支付可行性），不通过的方案无法投递；10 类 AI 角色协同（客户、地接社、酒店、车队、票务、司导、导演、评分、画像、教研），六帽并行审查，未通过审查的内容打回重做；人工校准集约束评分模型，未通过校准不写回画像；画像与难度闭环，答错降维解释、答对提升档位，下一单的考核点由画像反推；15 门语言、23 个客源市场，客户人设、语种与音色同源，客户全程只说母语；外部数据与资源能力按 MCP 工具契约暴露（天气、路线、汇率、询价、交付投递、合规校验等 11 个工具），为与携程及供应商系统对接预留，更换实现不改契约。

**预期提升（据一线调研测算）**

- 单个新人：4 个月纯投入期缩短 30%（约 1.2 个月），按综合人力成本 8,000 元/月计，节省培养成本约 1 万元；
- 带教师傅：每天约 1 小时的重复答疑中 60% 由系统承接，每人每年释放约 150 小时工时；
- 一家年招 5 名新人的旅行社：年节省约 5 万元量级；
- 漏算保险与停车费、酒店超售临时换房、车辆故障临时调度、高铁票不足多购一站四类高频损失场景，可在上岗前反复练掉，不再由真实客户承担试错成本。

**对携程的价值**：训练内容与界面同源于平台真实工作流，学员产出直接对齐平台考核口径；商户培养周期缩短、履约质量提升，商户留存与平台服务口碑随之改善。
