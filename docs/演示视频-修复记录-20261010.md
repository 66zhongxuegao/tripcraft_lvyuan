## 一、为什么之前一直「文不对题」

三个独立原因，全部已修：

1. **时间轴漂移（最严重）**
   `narration-full.mp3` 之前是用约 `0.55s` 的句间静音拼的，而 `index.html` 的播放器按 `DUR[k]+500ms` 换镜，两条时间轴越走越差，到片尾累计差 **约 2.3 秒**——听起来在讲第 N 句，画面还停在第 N-1 句。
   - 修复：用 `apad=pad_dur=0.5` 重拼 `narration-full.mp3`，时长精确等于 `ΣDUR + 45×0.5 = 401.46s`，与播放器完全一致。
2. **录屏本身有约 2.35s 的起始偏移**
   Playwright 录制的 webm 时间轴比页面 JS 时间轴晚约 2.35s（句 7→句 40 实测稳定在 2.0~2.55s）。
   - 修复：合成时对视频输入加 `-ss 2.35`。修完后用 `ffprobe -f lavfi movie=...,select=gt(scene,0.25)` 抽查，换镜点与 `ΣDUR` 的偏差 **<0.15s**。
3. **每个视频分镜开头有 1~3 秒黑屏**
   播放器每换一个 video 分镜都新建 `<video>` 元素并 seek，元素拿到数据前显示 `.vframe` 的深色底。
   - 修复：① 加 `.vframe video{background:#fff}`；② 静态服务器 `serve_range.py` 补 `Cache-Control`；③ 播放器改为**按 src 复用同一个 video 元素**（`VP` 池 + `mountVid()`）。修完 0.9s 时已能看到画面。
